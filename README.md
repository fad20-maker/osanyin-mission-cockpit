# Cockpit mission Abidjan – vitrine équipe

Interface de consultation, en lecture seule, du suivi de la mission du consortium Osanyin à Abidjan (16–31 octobre 2026).

- `site/` : page publiée (hébergement statique).
- `site/data.enc.json` : données de suivi, chiffrées ; elles s'ouvrent avec le code d'accès équipe.
- `tools/export.py` : préparation des données publiées (le journal et les comptes rendus ne sont jamais publiés).

Les données sont mises à jour par la coordination ; ne pas modifier ce dépôt à la main.
